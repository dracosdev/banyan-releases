# Security / Segurança

**Please don't report security issues in public issues or discussions.**
Write to **suporte@banyan.tools** with what you found and how to reproduce it. We reply as soon as possible and keep you posted until it's fixed.

**Não reporte falhas de segurança em issues ou discussions públicas.**
Escreva para **suporte@banyan.tools** contando o que encontrou e como reproduzir. Respondemos o quanto antes e mantemos você informado até a correção.
