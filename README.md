# Banyan

**Every branch can take root.**

Banyan is a visual Git client for macOS, Linux, and Windows — built for people who ship code. A clean commit graph, highlighted diffs, account integrations, and cloud sync across devices. Free to use.

> This repository contains only releases and installers, and is where you report bugs and talk with us. The source code is in a private repository.

## Features

- **Git Graph** — Visual commit graph with colored branching lines, Gravatar avatars, and branch filtering
- **Highlighted Diff** — Syntax-highlighted diffs with support for 190+ languages
- **WIP Panel** — Stage, unstage, and discard changes with a clean interface
- **Dark & Light Themes** — Multiple skins and accent colors, with system-match mode
- **Account integrations** — Sign in to your Git hosting account and push, pull and review pull requests
- **Cloud Sync** — Preferences, Git profiles, and integrations synced across up to 3 devices
- **File Watcher** — Real-time filesystem change detection, always in sync
- **Update checks** — Banyan lets you know when a new version is out
