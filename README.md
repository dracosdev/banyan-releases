# Banyan

**Banyan** é um aplicativo Android para assistir filmes, séries, animes e canais ao vivo diretamente no seu dispositivo.

> ⚠️ Este repositório contém apenas os **releases** e o **readme** do projeto. O código-fonte está em um repositório privado separado.

## Download

Baixe a versão mais recente na [página de releases](https://github.com/anomalyco/banyan-releases/releases).

## Funcionalidades

- Filmes, séries e animes sob demanda
- Canais ao vivo
- Interface otimizada para Android TV e dispositivos mobile
- Reprodução via WebView com suporte a múltiplos servidores

## Requisitos

- Android 6.0 (API 23) ou superior

## Instalação

1. Baixe o APK da [última release](https://github.com/anomalyco/banyan-releases/releases)
2. Habilite "Instalar de fontes desconhecidas" nas configurações do seu dispositivo
3. Abra o arquivo APK baixado e siga as instruções de instalação
